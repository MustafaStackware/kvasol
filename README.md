# KVASol Website

Coming soon landing page for [kvasol.com](https://kvasol.com).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static export is written to `out/` for GitHub Pages.

## Deploy

Pushes to `main` trigger the **Deploy to GitHub Pages** workflow. Custom domain: `kvasol.com`.
